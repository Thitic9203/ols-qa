## สรุปสั้น (Executive Summary)

บอร์ดสดของรอบตรวจสาเหตุ smoke บน dev (17/Sep ~11.05 AM) ถูกเผยแพร่ **2 ฉบับติดกันโดยที่ช่องสรุป
ผ่าน/ไม่ผ่าน/ยังไม่ทดสอบ ว่างเปล่า** สาเหตุคือข้อมูลบอร์ดใส่ `tileTotal` มาโดยที่ `tileRows` เป็นอาเรย์ว่าง ส่วน
`build_board.js` ตอนนั้นเรนเดอร์ `tileTotal` ไว้ใน `if (tileRows.length && tileTotal)` ก้อนเดียว ข้อมูลจึงตกไปใช้
ช่องทางสำรอง `tiles` ที่ไม่มีอยู่ ได้ `<div class="tiles"></div>` **โดยไม่มีคำเตือนใดๆ** และ `check_theme.js` ขึ้น
`THEME OK` ทั้ง 2 ฉบับเพราะมันวัดเฉพาะธีม ไม่ได้วัดเนื้อหา ฉบับแรกถูกส่งลิงก์ให้เจ้าของงานก่อนอ่านกลับ
จับได้ตอนอ่านกลับฉบับที่ 2 แก้ที่ตัวสร้างบอร์ดแล้ว — ตอนนี้ `tileTotal` กับ `tileRows` เรนเดอร์อิสระต่อกัน
และมีคำเตือนเมื่อ `tileTotal` ไม่มี tiles

## 1. ปัญหา (Problem Statement)

- บอร์ด 2 ฉบับของรอบเดียวกันเผยแพร่โดยที่ส่วน Overall ไม่มีตัวเลขใดๆ — HTML ที่ได้คือ `<div class="tiles"></div>` เปล่า
- ข้อมูลต้นทางมี `tileTotal` ครบ (4 ช่อง) แต่ `tileRows: []`
- `check_theme.js` ขึ้น `THEME OK` ทั้ง 2 ฉบับ — ด่านนี้วัดธีม/สี/ฟอนต์ ไม่ได้วัดว่าเนื้อหาขึ้นครบ
- ลิงก์ฉบับแรกถูกส่งให้เจ้าของงาน **ก่อน** อ่านเวอร์ชันที่ live กลับมาตรวจ

**สิ่งที่ควรจะเป็น:** ตัวสร้างต้องเรนเดอร์สรุปทุกกรณีที่มีข้อมูล และต้องปฏิเสธหรือเตือนดังๆ เมื่อข้อมูลอยู่ในรูปที่มันเรนเดอร์ไม่ได้
(กฎเดียวกับ #0020) · และห้ามส่งลิงก์ก่อนอ่านกลับ (กฎเดียวกับ #0018)

## 3. สาเหตุโดยละเอียด (Root Cause Analysis)

### 5 Whys

1. **ทำไมช่องสรุปว่าง?** — เพราะ `tileTotal` ไม่ถูกเรนเดอร์
2. **ทำไมไม่ถูกเรนเดอร์?** — เพราะเงื่อนไขมัดมันไว้กับ `tileRows.length` ที่เป็น 0
3. **ทำไมถึงมัดไว้ด้วยกัน?** — เพราะตอนเขียน ทุกบอร์ดมีทั้งสองส่วนเสมอ เงื่อนไขจึงถูกต้อง "โดยบังเอิญของข้อมูล"
   ไม่ใช่เพราะสองส่วนนี้ขึ้นต่อกันจริง
4. **ทำไมไม่มีใครเตือน?** — เพราะทางตกหล่นไปที่ `tiles` ซึ่งเป็นช่องคนละช่อง และการที่มันว่างถือเป็นกรณีปกติของ
   โค้ดเส้นนั้น — "ผิดรูป" กับ "ไม่มีข้อมูล" ถูกยุบเป็นผลลัพธ์เดียวกัน (คลาสเดียวกับ #0003 · #0005 · #0020)
5. **root cause:** ตัวสร้างบอร์ดไม่มีสถานะที่สามคือ "ข้อมูลมาในรูปที่ฉันเรนเดอร์ไม่ได้" มีแค่ "เรนเดอร์" กับ "ว่าง"

**ทำไมชั้นป้องกันที่มีอยู่ถึงไม่จับ:** `check_theme.js` เป็นด่านของ **ธีม** ไม่ใช่ด่านของ **เนื้อหา** — ไม่มีด่านไหนใน
สายนี้ที่ถามว่า "สรุปมีตัวเลขไหม" · และกฎ "อ่าน live กลับมาก่อนส่งลิงก์" (#0018) มีอยู่แล้วแต่ถูกข้ามในฉบับแรก

## 5. แนวทางการแก้ไข (Fix)

- แก้ `board/build_board.js` ให้ `tileTotal` และ `tileRows` เป็นส่วนอิสระ — ปัจจุบันอยู่ที่บรรทัด 232-241
  และช่องทางสำรอง `tiles` เหลือไว้เฉพาะกรณีไม่มีทั้งคู่ (บรรทัด 243-244)
- เพิ่มคำเตือนออก stderr เมื่อ `tileTotal` มีแต่ไม่มี `tiles` ข้างใน (บรรทัด 235-236)
- เขียนคอมเมนต์อธิบายเหตุไว้ที่บรรทัด 224-231 เพื่อไม่ให้ถูกมัดกลับเข้าด้วยกันอีก

**ยืนยันแล้วด้วย:** อ่านซอร์สปัจจุบันของ `board/build_board.js` — บรรทัด 232 `if (tileTotal) {` แยกจาก
บรรทัด 240 `if (tileRows.length) {` และบรรทัด 243 `if (!tileTotal && !tileRows.length)` · บอร์ดฉบับถัดมา
ของรอบเดียวกันแสดงช่องสรุปครบและถูกอ่านกลับจากเวอร์ชัน live แล้ว
