## 3. สาเหตุโดยละเอียด (Root Cause Analysis)

### 5 Whys

1. **ทำไมพลิกผิด?** — ตัดสินจากสิ่งที่เห็นในเฟรม (แถบคำบรรยาย) โดยไม่เทียบมติ
2. **ทำไมไม่เทียบมติ?** — ไม่ได้อ่าน note ของ verdict เดิมก่อนสั่ง และไม่ได้เปิด memory ที่เกี่ยวกับแคปชัน
3. **ทำไมรีบ?** — เจ้าของงานเร่ง ("นาน") และผมพยายามปิดรายการที่เหลือให้เร็ว
4. **ทำไมเครื่องมือไม่หยุด?** — `put_verdict.py` ไม่เตือนเมื่อพลิกผลที่มี note อ้างมติ (`flip-approved-…`)
5. **root cause:** ไม่มีขั้นบังคับอ่าน verdict เดิม/มติที่เกี่ยวก่อนพลิกกลับทิศ (ผ่าน→ไม่ผ่าน)

**ทำไมชั้นป้องกันที่มีอยู่ถึงไม่จับ:** gate ของ put_verdict บังคับ er-frames เฉพาะทิศ "ผ่าน" · ทิศ "ไม่ผ่าน" ไม่มีด่าน
