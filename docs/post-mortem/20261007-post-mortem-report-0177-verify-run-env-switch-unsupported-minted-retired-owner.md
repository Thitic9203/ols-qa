## สรุปสั้น (Executive Summary)

เธรดหลักรันชุด 95 เทสต์บน commit ของ branch ตัวดัก โดยตั้ง `E2E_SKIP_FIXTURE_OWNERS=1` ตามคำสั่งของบอท smoke ทั้งที่สวิตช์นี้มีอยู่แค่ในไฟล์ที่แก้ค้างบน main checkout (ไม่อยู่ใน commit ใด) และเธรดหลักเองตรวจพบเรื่องนี้ไปแล้วก่อนหน้า
setup จึงหาไฟล์ session ของ owner ไม่เจอแล้วเรียก `mintState` ส่ง `POST /auth/login-with-email` ให้บัญชี owner ที่เลิกใช้ 1 ครั้ง (HTTP 400) setup ล้ม และ 95 เทสต์ไม่ได้รัน ส่วนบรรทัดท้าย log เขียน `rc=0` ผิด เพราะอ่าน `$?` หลัง `$(date)`
แก้โดยรันซ้ำด้วย `--no-deps` (ตรวจด้วย `--list` แล้วได้ 95 เทสต์ชุดเดียวกับรอบ 14:33 ไม่มี setup และไม่มีเคส owner) และเก็บ `rc=$?` ทันทีหลังคำสั่ง

## 3. สาเหตุโดยละเอียด (Root Cause Analysis)

### 5 Whys

1. **ทำไมมีการล็อกอินให้บัญชีที่เลิกใช้?** — เพราะ setup project รันด้วย และ `auth.setup.ts:58` เรียก `mintState` เมื่อไม่มีไฟล์ session ของ owner
2. **ทำไม setup รัน?** — เพราะคำสั่งไม่มี `--no-deps` และ `--grep @safe` ไม่ได้กรองเทสต์ของ setup ออก (`--list` ยืนยันว่ามี `setup auth` ติดมา)
3. **ทำไมคิดว่าบัญชี owner จะถูกข้าม?** — เพราะตั้ง `E2E_SKIP_FIXTURE_OWNERS=1` ตามบอท ทั้งที่ commit นั้นไม่มีโค้ดที่อ่านสวิตช์นี้
4. **ทำไมไม่จับได้ก่อนรัน?** — เพราะไม่ได้ `--list` ดูชุดเทสต์ที่จะรันจริง และไม่ได้เทียบคำสั่งกับรอบ 14:33 ที่ได้ 95 เทสต์
5. **ทำไมไม่มีขั้น preflight?** — เพราะการรันด้วยมือไม่มีกฎบังคับให้พิสูจน์ชุดเทสต์ก่อนรัน มีแต่ `smoke_watch.py` ที่ทำงานกับไฟล์ค้างบน main checkout — root cause

**ทำไมชั้นป้องกันที่มีอยู่ถึงไม่จับ:** ไม่มี guard ดูคำสั่ง `playwright test` ที่ agent พิมพ์เอง · บัญชีที่เลิกใช้ยังอยู่ใน `accountsForRun()` ของ commit ที่ push แล้ว จึงไม่มีชั้นในโค้ดที่ปฏิเสธการ mint ให้บัญชีนี้

## 6. แนวทางการป้องกันไม่ให้เกิดปัญหาซ้ำ (Prevention)

1. ก่อนสั่ง `playwright test` ด้วยมือทุกครั้ง ต้อง `--list --reporter=json` ด้วย argv เดียวกัน แล้วแนบจำนวนเทสต์ + ยืนยันว่าไม่มี project `setup` และไม่มีเคส owner ก่อนรันจริง
2. env switch ที่คำสั่งใช้ ต้อง `grep` ยืนยันว่าอยู่ใน commit ที่รัน ถ้าไม่อยู่ = ห้ามใส่
**กฎที่เพิ่มจากเหตุนี้:** `docs/ENVIRONMENT.md` — สั่ง `playwright test` ด้วยมือต้อง `--list` ด้วย argv เดียวกันก่อน ยืนยันไม่มี `setup`/บัญชีที่เลิกใช้ · env switch ต้องอยู่ใน commit ที่รัน · `rc=$?` ทันที ตัดสินจาก `run.json`

3. เสนอเจ้าของงาน: commit สวิตช์ `E2E_SKIP_FIXTURE_OWNERS` ที่ค้างอยู่ (ไฟล์ EDITED) หรือทำให้ setup ปฏิเสธการ mint บัญชีที่ทำเครื่องหมายว่าเลิกใช้ — ต้องได้คำสั่งก่อนเพราะเป็นไฟล์ที่มีคนแก้ค้าง
