## 3. สาเหตุโดยละเอียด (Root Cause Analysis)

### 5 Whys

1. **ทำไมรันงานหนักตรงๆ?** — เพราะผมไม่ได้นึกถึงกฎ heavy.sh ตอนสั่งรัน
2. **ทำไมไม่นึกถึง?** — กฎอยู่ใน memory ไฟล์เดียว ไม่ได้อยู่ใน `CLAUDE.md` ของ repo และไม่ได้อยู่ในหมวดที่ผมเปิดก่อนรัน
3. **ทำไมไม่มีอะไรเตือนตอนรัน?** — ไม่มี hook/guard ใดตรวจว่าคำสั่ง Playwright/suite ถูกห่อด้วย `heavy.sh`
4. **ทำไม ask-guard จับได้แต่ไม่ใช่ตอนรัน?** — ask-guard ทำงานเฉพาะตอนจะถามเจ้าของงาน
5. **root cause:** กฎ "งานหนักผ่าน heavy.sh" บังคับด้วยความจำเท่านั้น — เป็นคลาสเดียวกับ #0203 (กฎข้อความล้มซ้ำ) จึงต้องมีชั้นเครื่องมือ

**ทำไมชั้นป้องกันที่มีอยู่ถึงไม่จับ:** ไม่มีชั้นเครื่องมือ · memory ไม่ได้ถูกโหลดตอนรัน · ask-guard จับได้โดยบังเอิญหลังเกิดเหตุ
