## 3. สาเหตุโดยละเอียด (Root Cause Analysis)

กฎ #0038 ถูกเขียนไว้ในรูป "อย่ายิง endpoint นี้" ผมจึงเขียนคำสั่งงานในรูปเดียวกันคือห้ามเครื่องมือที่ยิง endpoint นั้น
แต่ endpoint เดียวกันถูกเรียกได้จากหน้าเว็บเองทุกครั้งที่หน้าเว็บเห็นว่าโทเคนใกล้หมด ซึ่งไม่ต้องมีใครสั่ง

### 5 Whys

1. **ทำไมโทเคนถูกหมุน?** — หน้าเว็บ NDLP เรียก refresh เองตอนโหลด
2. **ทำไมหน้าเว็บ NDLP ถูกเปิดด้วยไฟล์ session?** — เลนต้องการรู้ว่าหน้าต้นทางเปิดได้โดยไม่ต้องใส่รหัสผ่านไหม
3. **ทำไมเลนไม่รู้ว่าอันตราย?** — คำสั่งงานห้ามแค่ตัวเครื่องมือ ไม่ได้ห้ามการเปิดเว็บที่ออกโทเคนนั้น
4. **ทำไมคำสั่งงานเขียนแคบแบบนั้น?** — ผมแปลกฎ #0038 เป็นรายชื่อเครื่องมือที่ห้าม ไม่ใช่คุณสมบัติของปลายทาง
5. **ทำไมไม่มีชั้นอื่นกันไว้?** — ตัวอัดไม่มีโหมดเซฟ `storageState` กลับหลังจบ และไม่มีข้อตรวจว่าโดเมนที่จะเปิดเป็นผู้ออกโทเคนหรือไม่
  **root cause:** ข้อห้ามถูกผูกกับ *ผู้ยิง* ไม่ได้ผูกกับ *ปลายทางที่หมุนโทเคน*
