## 3. สาเหตุโดยละเอียด (Root Cause Analysis)

ตัวสร้างบอร์ดของรอบใหม่ถูกเขียนขึ้นใหม่ ไม่ได้ต่อจากตัวสร้างที่อ่านต้นฉบับ เนื้อหากล่องเกณฑ์จึงถูกแต่งจาก "กฎที่สำคัญของรอบนี้" แทนที่จะคัดจากต้นฉบับ การแช่แข็งถูกเก็บไว้ใน memory เท่านั้น ไม่มีด่านในตัวสร้าง

### 5 Whys

1. **ทำไมกล่องเกณฑ์มี 4 (แล้ว 3) บรรทัด?** — เพราะ `gen_board_0923.py` เขียนเกณฑ์เป็นลิสต์ตายตัวของรอบนี้
2. **ทำไมตัวสร้างเขียนเอง?** — เพราะตัวสร้างของรอบ 23/Sep เขียนใหม่ ไม่ได้อ่าน `ul.crit-list` ของต้นฉบับ
3. **ทำไมไม่มีอะไรหยุดตอนสร้าง?** — เพราะ `check_theme.js` / ขั้นตรวจก่อน publish ตรวจธีมและข้อมูลเลน ไม่ตรวจเนื้อหากล่องเกณฑ์เทียบต้นฉบับ
4. **ทำไมการลบตามคำสั่ง 21.0x ไม่ทำให้เห็นปัญหา?** — เพราะเธรดหลักแก้ลิสต์ที่มีอยู่โดยไม่ถามว่าลิสต์นั้นมาจากไหน และตีความคำสั่ง "ตัดออกจากบอร์ด" ว่าให้แตะกล่องเกณฑ์ ซึ่งไม่ควรมีบรรทัดนั้นตั้งแต่แรก
5. **ทำไมคลาสนี้เกิดซ้ำหลัง 13/Sep และ #0091?** — เพราะมาตรการของทั้งสองครั้งเป็น memory/บรีฟ ไม่ใช่ด่านที่ผูกกับต้นฉบับ (root cause: ส่วนของบอร์ดที่แช่แข็งไม่มีแหล่งเดียวที่ตัวสร้างทุกตัวต้องอ่าน)

**ทำไมชั้นป้องกันที่มีอยู่ถึงไม่จับ:** memory `vdo-board-criteria-10line-frozen` ต้องถูกอ่านเอง · มาตรการของ #0091 เน้นช่องสรุปตัวเลข ไม่ได้ครอบกล่องเกณฑ์ · `check_theme.js` ไม่ตรวจเนื้อหา
