# Post-mortem debt ledger — หนี้เอกสารที่ยังไม่ปิด

**ไฟล์นี้คือชั้นที่ 2 ของแนวป้องกัน 10 ชั้น** — เขียนแถวใหม่ **ทันทีในเทิร์นที่รู้ตัวว่าพลาด** ใช้เวลาไม่กี่วินาที
แล้วค่อยเขียนรายงานฉบับเต็มทีหลัง ถ้าไม่จดตรงนี้ก่อน เซสชันจบเมื่อไหร่ความผิดพลาดก็หายไปกับเซสชัน

**อย่าแก้หัวตารางและอย่าเปลี่ยนจำนวนคอลัมน์** — hook และ validator อ่านไฟล์นี้ตรงๆ
(`.claude/hooks/postmortem-debt.sh` · `tools/postmortem-guard/check.js`)

## สถานะที่ใช้ได้ มี 3 ค่าเท่านั้น

| สถานะ | ความหมาย | เงื่อนไข |
|-------|----------|----------|
| `OPEN` | รู้ว่าพลาดแล้ว แต่ยังไม่มีรายงาน | ทุกชั้นจะเตือนจนกว่าจะปิด · pre-commit บล็อกคอมมิตอื่นไว้ |
| `DONE` | เขียนรายงานแล้ว | คอลัมน์ **รายงาน** ต้องเป็นชื่อไฟล์รายงานที่มีอยู่จริง |
| `WONTFIX` | เจ้าของงานตัดสินว่าไม่ต้องเขียน | คอลัมน์ **รายงาน** ต้องเขียนเหตุผล + วันที่ที่เจ้าของงานสั่ง |

ค่าอื่นนอกจาก 3 ค่านี้ = validator ปฏิเสธ (fail-closed) เพราะสถานะที่อ่านไม่ออกคือสถานะที่ไม่มีใครตามต่อ

## วิธีเขียนแถวใหม่

1. **ID** = `PM-<วันที่ ISO>-<ลำดับของวันนั้น 2 หลัก>` เช่น `PM-2026-09-05-02`
2. **เกิดเมื่อ** = วันที่ความผิดพลาดเกิด ไม่ใช่วันที่รู้ตัว
3. **อาการ** = สิ่งที่ผิดจริง เขียนสั้นแต่ชี้ได้ว่าเรื่องอะไร ห้ามเขียนกว้างจนตามกลับไม่ได้
4. **ที่มา** = งานหรือคำสั่งที่กำลังทำตอนนั้น (ระบุไว้เพื่อหาบริบทย้อนหลัง ไม่ใช่เพื่อโยนความผิด — คนสั่งไม่ใช่คนผิด)
5. **สถานะ** = `OPEN` ก่อนเสมอ
6. **รายงาน** = `—` ตอนเปิด · ใส่ชื่อไฟล์เมื่อเขียนเสร็จแล้วเปลี่ยนเป็น `DONE`
